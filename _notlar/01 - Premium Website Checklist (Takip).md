# Premium Website Checklist — Takip Listesi

Kaynak: "The Premium Website Checklist" (Marka Denemeleri klasörü).
Sitedeki her madde burada takip edilecek. Tamamlananlar [x] işaretlenir.

---

## 1. Temel: Site bilinçli duruyor mu?

- [x] **Amaç ilk bakışta anlaşılıyor** — Ziyaretçi kaydırmadan önce ne yaptığımızı, kime hitap ettiğimizi ve neden önemli olduğunu anlıyor.
- [x] **"Kendim yaptım" hissi yok** — Hiçbir şey şablondan çıkmış, aceleye gelmiş görünmüyor. Sade düzenler bile bilinçli duruyor.
- [x] **Anında güven sinyali** — Profesyonel ton, kendinden emin dil, görsel netlik.

## 2. Özel görseller ve grafikler: Derinlik

- [x] **Özel grafikler (stok ikon değil)** — Görsel öğeler markaya özel tasarlanmış.
- [ ] **Her grafiğin bir işi var** — Dikkati yönlendiriyor, metni bölüyor, bilgiyi sindirilebilir kılıyor.
- [ ] **Marka ile uyumlu görseller** — Ton, renk paleti ve kişilik tutarlı.
- [x] **Görsel gürültü yok** — "Öylesine" duran hiçbir öğe yok.

> Eren'in notu: Stok görseller üzerinde önden çalışılabilir, görsel listesine bakılabilir.

## 3. Marka stratejisi: Profesyonel temel

**Logo**
- [x] **Bilinçli, profesyonel logo** — Sade olabilir, amatör olamaz.

**Renk paleti**
- [x] **Bütünlüklü renk sistemi** — Renkler tutarlı bir ruh hâli kuruyor, kaos yaratmıyor.
- [x] **Çeşitlilik yerine kısıtlılık** — Az sayıda renk, kendinden emin kullanım.

**Tipografi**
- [x] **Nitelikli yazı tipi seçimi** — Yazı tipi markayı yukarı çekiyor.
- [x] **Önce okunabilirlik** — Eski moda, çocuksu veya zor okunan yazı tipi yok.

## 4. İnce animasyon: Boğmadan canlılık

- [x] **Kaydırmaya bağlı hareket** — Öğeler kaydırdıkça doğal biçimde beliriyor.
- [x] **Etkileşim geri bildirimi** — Düğme ve bağlantılar üzerine gelince tepki veriyor.
- [x] **Dikkat dağıtan numara yok** — Dönen, zıplayan hiçbir şey yok.
- [x] **Sürtünme azaltılmış** — Animasyon yönlendiriyor, şaşırtmıyor.

> Eren'in notu: Yayınlar listesinde makalenin üstüne gelince arka plan siyaha dönebilir ya da altta lacivert bir imleç belirebilir.

## 5. Stratejik yapı: Site haritası, kullanım akışı, yönlendirmeler

- [x] **Mantıklı site haritası** — Sayfalar tek tek değil, birlikte anlam taşıyor.
- [x] **Net kullanıcı yolculuğu** — Her sayfa doğal olarak bir sonrakine bağlanıyor.
- [x] **Karar felci yok** — Ziyaretçi bir sonraki adımı hep biliyor.
- [x] **Güçlü, görünür yönlendirmeler (CTA)** — Eyleme çağrı açık ve kolay.
- [x] **SEO'ya hazır yapı** — Başlık hiyerarşisi, iç bağlantılar, içerik düzeni hem insan hem arama motoru için kurgulanmış.

> Eksik sayfa: **Kariyer** (Eren'in notu).
> Eksik sayfa: **Çerez Politikası** ve **KVKK Aydınlatma Metni** — nerede görüneceğine karar verilecek.
> Eklenecek: **Başvuru / görüşme talebi formu** (ad soyad, konu, iletişim bilgileri).
> Eklenecek: İletişim sayfasında **harita**.

## 6. Sahiplik: Siteyi kendin yönetebiliyor musun?

- [x] **İçerik kolayca güncellenebiliyor** — Basit değişiklikler için geliştiriciye ihtiyaç yok.
- [x] **Kara kutu değil** — Site kırılgan, kilitli veya ürkütücü değil.
- [x] **Uzun ömür için kurulmuş** — Sayfa eklemek, hizmet güncellemek, içerik tazelemek kolay.

## 7. Devir ve yayın sonrası

- [x] **Yapılandırılmış devir eğitimi** — Sitenin nasıl yönetileceği adım adım anlatılmış (bu projede: `_notlar/Kullanim Rehberi.md`).
- [ ] **Beklentiler net** — Neyi kendin yapabilirsin, ne zaman yardım istemelisin.
- [ ] **Yayın sonrası destek** — Sorunlar sürtünmesiz çözülüyor.
